# EtherWalletPlus

EtherWalletPlus is a decentralized, multi-chain secure gateway providing real-time transaction tracking for multi-asset support on a robust platform.

EtherWalletPlus is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/EtherWalletPlus.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

EtherWalletPlus is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
